# Merlon Check

A free, open, offline verifier for Merlon Accountability Receipts. Anyone can check a receipt, a chain of receipts or a log checkpoint without trusting Merlon and without a network connection.

**Status: not yet released.** The first version (v0.1) is built in Phase 0 (briefs P0-05 and P0-06): a command-line tool and an offline web page (WebAssembly).

- Licence: Apache-2.0 (ADR-012).
- This repository is a mirror of `check/` in the Merlon monorepo. Releases are signed.
- Merlon Check is free in every configuration (P-05).
